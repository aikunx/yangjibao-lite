# 基准配置文件（Baseline Profile）
#
# 作用：告诉 ART 哪些方法在安装时就做 AOT 编译，
# 避免首次启动时逐行解释执行。官方实测可让启动与首次交互提速约 30%。
# 参考：https://developer.android.google.cn/topic/performance/baselineprofiles
#
# 格式（ART profile 文本格式）：
#   H = Hot            热方法
#   S = Startup        启动阶段调用
#   P = Post-startup   启动后不久调用
#   前缀可组合，如 HSPL 表示同时属于启动与热路径
#
#   重要：只有「方法规则」（带 ->）可以带标志；
#        「类规则」（以分号结尾）不允许带任何标志。
#
# 这里手工覆盖「冷启动 -> 首屏渲染 -> 拉取行情 -> 切 Tab」这条主路径。
