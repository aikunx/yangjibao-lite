# 养基宝 Lite — 信息架构设计

## 一、页面层级（三层，不重复）

```
┌─ 一级：底部导航（5 个）
│   持仓 · 自选 · 行情 · 情绪 · 我的
│
├─ 二级：列表页（每页都是可点的列表）
│   持仓 → 点基金 → ③ 基金详情
│   自选 → 点基金 → ③ 基金详情
│   行情 → 板块/概念/个股 三个分段 → 点某项 → ③ 板块详情
│   情绪 → 宝妈指数列表 → 点某项 → ③ 板块详情
│   我的 → 设置项
│
└─ 三级：详情页（从任意列表点进来，顶部有返回）
    ③ 基金详情  /  ③ 板块详情
```

**原则：一级负责「去哪里」，二级负责「有哪些」，三级负责「具体怎样」。**
不再有顶栏大标签与底部导航重复的问题。

## 四、数据结构

```js
// 板块（东财资金流）
Sectors = [{
  code, name,
  pct,                    // 涨跌幅 %
  mainIn,                 // 主力净流入（元）
  superIn, largeIn,       // 超大单、大单（元）
  midIn, smallIn,         // 中单、小单=散户（元）
  mainPct,                // 主力净占比 %
  up, down,               // 上涨/下跌家数
  leader, leaderPct,      // 领涨股
}]

// 宝妈情绪
Mom = [{
  id, name,
  score,                  // 0-100
  heat,                   // 热度值
  buySell,                // "0.5:1"
  status, statusClass, color,
  change,                 // 相对上次变化
  keywords: [],
  etf: 'sh518880',        // 对应 ETF，可用于拉分时
}]
```

## 五、刷新策略

| 数据 | 间隔 | 说明 |
|---|---|---|
| 指数行情 | 3 秒 | 与数据源更新同步 |
| 持仓估值 | 3 秒 | |
| 板块资金流 | 30 秒 | 分钟级数据 |
| 宝妈情绪 | 60 秒 | 小时级数据 |

**只在当前可见页刷新**，切走即停，避免后台空转耗电。
